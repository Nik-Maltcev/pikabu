# Перенос BizMap с Railway на VPS

## Что тебе нужно

- VPS (Ubuntu 22.04, 4 vCPU, 8 GB RAM, 60 GB диск)
- Доступ к Railway (для дампа БД)
- Домен bizmap.space (уже есть)

---

## Порядок действий (по шагам)

### ШАГ 1: Сделай дамп базы данных с Railway

Открой Railway → Postgres → вкладка Connect → скопируй DATABASE_URL.

На своём компе (нужен установленный postgresql):

```
pg_dump "postgresql://USER:PASS@HOST:PORT/railway" --no-owner --no-acl -Fc > bizmap.dump
```

Или через Railway CLI:
```
railway link
railway connect postgres
pg_dump -U postgres -Fc railway > /tmp/bizmap.dump
```

---

### ШАГ 2: Скопируй файлы на VPS

```
# Копируем папку deploy/ на VPS
scp -r deploy/* root@IP_ВАШЕГО_VPS:/opt/bizmap/

# Копируем backend
scp -r backend root@IP_ВАШЕГО_VPS:/opt/bizmap/backend

# Копируем frontend
scp -r frontend root@IP_ВАШЕГО_VPS:/opt/bizmap/frontend

# Копируем дамп БД
scp bizmap.dump root@IP_ВАШЕГО_VPS:/opt/bizmap/
```

---

### ШАГ 3: Заходим на VPS и настраиваем

```
ssh root@IP_ВАШЕГО_VPS
cd /opt/bizmap

# Настроить сервер (Docker, зависимости)
chmod +x *.sh
./setup-vps.sh

# Создать .env из примера и заполнить
cp .env.example .env
nano .env
```

В nano заполни все значения из Railway (Variables → каждого сервиса).

---

### ШАГ 4: Запусти

```
./start.sh
```

Если всё ок — увидишь "Backend работает! Frontend работает!"

---

### ШАГ 5: Восстанови базу данных

```
./restore-db.sh
```

Покажет сколько тем, постов и комментов восстановлено.

---

### ШАГ 6: Настрой DNS

В Cloudflare (или где домен):
- `A` запись: `www.bizmap.space` → IP VPS
- `A` запись: `api.bizmap.space` → IP VPS
- `A` запись: `bizmap.space` → IP VPS

Подожди 5-10 минут пока DNS разойдётся.

---

### ШАГ 7: Включи SSL

```
./setup-ssl.sh
```

Спросит email — введи свой. Сертификат получится автоматом.

---

### ШАГ 8: Настрой еженедельный парсинг

```
./setup-cron.sh
```

---

### ШАГ 9: Проверь

- Открой https://www.bizmap.space — должен работать фронт
- Открой https://api.bizmap.space/health — должен ответить
- Запусти тестовый анализ

---

### ШАГ 10: Выключи Railway

Когда убедился что всё работает — выключай сервисы в Railway.

---

## Полезные команды на VPS

```
cd /opt/bizmap

# Посмотреть логи
docker compose logs -f
docker compose logs backend -f
docker compose logs postgres -f

# Перезапустить
docker compose restart

# Остановить всё
docker compose down

# Обновить код (после git pull)
docker compose up -d --build backend frontend

# Зайти в базу
docker compose exec postgres psql -U bizmap -d bizmap
```

---

## Переезд на другой VPS в будущем

Всё что нужно:
```
# На текущем VPS — дамп БД
cd /opt/bizmap
docker compose exec -T postgres pg_dump -U bizmap -Fc bizmap > bizmap.dump

# Скопировать на новый VPS
scp -r /opt/bizmap root@НОВЫЙ_VPS:/opt/bizmap

# На новом VPS
cd /opt/bizmap
./setup-vps.sh
./start.sh
./restore-db.sh
./setup-ssl.sh
```

5 команд — 10 минут.
